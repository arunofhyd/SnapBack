01 / GEOMETRY PIXEL ACCURATE

Multi-Monitor Restoration

Remembers which app was on Display 1, Display 2, or your MacBook screen. Restores exact coordinates across varied DPI resolutions.

Display UUID Anchored
02 / TABS BROWSER SESSIONS

Active Browser Tabs

Doesn't just save window bounds — SnapBack snapshots open URLs in Safari and Chromium browsers to recreate your entire research session.

AppleScript & Native Session Engine
03 / SHORTCUTS HOTKEY TRIGGER

One-Key Snap

Assign global hotkeys to specific profiles (e.g., ⌘⌥1 for "Work", ⌘⌥2 for "Gaming/Media"). Instant transition with zero window flickering.

Sub-15ms Window Server Repositioning
04 / PRIVACY ON-DEVICE

Zero Cloud Telemetry

Window titles, project directories, and tab URLs are stored in a local JSON config on your disk. Never synced to any cloud backend.

Plaintext JSON Config (~/Library/Application Support)
05 / SCRIPTABLE CLI INTERACTION

Terminal Automation

Invoke SnapBack from shell scripts or Raycast extensions: snapback --save work or snapback --restore dev.

Shell & Raycast Interoperability
